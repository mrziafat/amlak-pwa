اپ PWA «املاک من»
نسخه اولیه موبایل‌محور

قابلیت‌ها:
- ثبت سریع بازدید
- ثبت خودکار مشتری و ملک در صورت جدید بودن
- ثبت پیگیری با تاریخ و ساعت
- داشبورد پیگیری امروز و عقب‌افتاده
- جست‌وجوی مشتری و ملک
- تماس مستقیم با مشتری از داخل گوشی
- ثبت صوتی یادداشت فارسی با Web Speech API در مرورگرهای پشتیبان
- نصب به‌صورت PWA و کارکرد آفلاین پس از اولین بارگذاری
- داده‌ها در همان دستگاه و مرورگر با localStorage نگهداری می‌شوند

اجرای سریع:
1) فایل‌ها را روی یک سرویس میزبانی HTTPS قرار دهید (مثلاً GitHub Pages یا هر هاست ساده).
2) آدرس را با Chrome/Edge روی گوشی باز کنید.
3) گزینه Add to Home Screen / نصب را بزنید.

نکته:
این نسخه برای نمونه اولیه است. برای استفاده حرفه‌ای چنددستگاهی، همگام‌سازی ابری، حساب کاربری، پشتیبان‌گیری، یادآوری واقعی سیستم‌عامل و گزارش‌های پیشرفته باید بک‌اند و پایگاه داده اضافه شود.
